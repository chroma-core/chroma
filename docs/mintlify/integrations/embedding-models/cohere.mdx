Chroma provides a convenient wrapper around Cohere's embedding API. This embedding function runs remotely on Cohere's servers, and requires an API key. You can get an API key by signing up for an account at [Cohere](https://dashboard.cohere.ai/welcome/register).

<Tabs>
<Tab title="Python" icon="python">

This embedding function relies on the `cohere` python package, which you can install with `pip install cohere`.

```python
import chromadb.utils.embedding_functions as embedding_functions

# Reads COHERE_API_KEY (or CHROMA_COHERE_API_KEY) from the environment
cohere_ef = embedding_functions.CohereEmbeddingFunction(model_name="embed-v5.0-pro")

collection = client.create_collection(name="docs", embedding_function=cohere_ef)
collection.add(ids=["1", "2"], documents=["document1", "document2"])
results = collection.query(query_texts=["a question"], n_results=2)
```

</Tab>

<Tab title="TypeScript" icon="js">

```typescript
// npm install @chroma-core/cohere

import { CohereEmbeddingFunction } from "@chroma-core/cohere";

// Reads COHERE_API_KEY from the environment
const embedder = new CohereEmbeddingFunction({ modelName: "embed-v5.0-pro" });

const collection = await client.createCollection({
    name: "docs",
    embeddingFunction: embedder,
});
```

</Tab>

</Tabs>

By default, Chroma uses `embed-v5.0-pro`. You can pass a different model with `model_name` (`modelName` in TypeScript). See Cohere's [Embed models](https://docs.cohere.com/docs/cohere-embed) page for the full list. Collections you already created keep the model they were created with.

Documents are embedded with Cohere's `search_document` input type and queries with `search_query`, so retrieval works as Cohere's models expect without extra setup.

### Index with Pro, query with Fast

`embed-v5.0-pro` and `embed-v5.0-fast` share one embedding space. You can embed documents with Pro and run queries with the lower-latency Fast model against the same collection:

<CodeGroup>

```python Python
cohere_ef = embedding_functions.CohereEmbeddingFunction(
    model_name="embed-v5.0-pro",
    query_model_name="embed-v5.0-fast",
)
```

```typescript TypeScript
const embedder = new CohereEmbeddingFunction({
    modelName: "embed-v5.0-pro",
    queryModelName: "embed-v5.0-fast",
});
```

</CodeGroup>

### Smaller embeddings

Embed v4.0 and newer models support Matryoshka embeddings, so you can trade a little accuracy for less storage by setting `output_dimension` (`outputDimension` in TypeScript), for example `1024`. This can't be changed after the collection is created.

<CodeGroup>

```python Python
cohere_ef = embedding_functions.CohereEmbeddingFunction(
    model_name="embed-v5.0-pro",
    output_dimension=1024,
)
```

```typescript TypeScript
const embedder = new CohereEmbeddingFunction({
    modelName: "embed-v5.0-pro",
    outputDimension: 1024,
});
```

</CodeGroup>

### Multilingual text

Embed 5 models are multilingual, so no separate model is needed:

```python
multilingual_texts = [
    'Hello from Cohere!', 'مرحبًا من كوهير!',
    'Hallo von Cohere!', 'Bonjour de Cohere!',
    '¡Hola desde Cohere!', 'Olá do Cohere!',
    'Ciao da Cohere!', '您好，来自 Cohere！',
    'कोहिअर से नमस्ते!'
]

cohere_ef(input=multilingual_texts)
```

### Multimodal model example

```python
import os
from datasets import load_dataset, Image


dataset = load_dataset(path="detection-datasets/coco", split="train", streaming=True)

IMAGE_FOLDER = "images"
N_IMAGES = 5

# Write the images to a folder
dataset_iter = iter(dataset)
os.makedirs(IMAGE_FOLDER, exist_ok=True)
for i in range(N_IMAGES):
    image = next(dataset_iter)['image']
    image.save(f"images/{i}.jpg")


multimodal_cohere_ef = CohereEmbeddingFunction(model_name="embed-v5.0-pro")
image_loader = ImageLoader()

multimodal_collection = client.create_collection(
    name="multimodal",
    embedding_function=multimodal_cohere_ef,
    data_loader=image_loader)

image_uris = sorted([os.path.join(IMAGE_FOLDER, image_name) for image_name in os.listdir(IMAGE_FOLDER)])
ids = [str(i) for i in range(len(image_uris))]
multimodal_collection.add(ids=ids, uris=image_uris)

retrieved = multimodal_collection.query(query_texts=["animals"], include=['data'], n_results=3)

```
