# Compare quality at a prespecified high-recall target

This runtime-only package evaluates the exact retained reference, one-owner and four-owner 16K snapshots. It performs no build, construction, topology change or query-policy sweep. Those trees come from source epoch c810fb55c2db4ac5aefc55bf7dc839e096906f119021d58a7940ec5909804f22 and predate live-prefix and split-input filtering. Results characterize those saved trees, not the newest combined construction path. The exact reused Linux binary has SHA-256 89e8ecedcc5ae4fb92e5819c70178f9374ce4561cd80187e3196f52e795805d7 and 17,824,864 bytes.

The goal is a conditional comparison at 95% recall with a one-percentage-point paired margin. The package reserves 288 document queries by the fixed formula in cohort-selection.json. It uses 32 for calibration and 256 for evaluation. All IDs are outside the dense indexed prefix, and exact vector-bit duplicates against that prefix or across query subsets reject without replacement. This proves ID and bit exclusion only. The documents are not a representative natural-query sample, may be dependent or semantically duplicated, and may appear in older research indexes or model training. The untouched claim applies to this protocol's evaluation outcomes, not all research history.

The setup reads 884,736 logical query bytes and copies 50,331,648 prefix bytes once. It computes fresh FP64 top-100 ground truth against that prefix using four byte-identical modules from the accepted exact engine, with corpus blocks of 8,192 and query blocks of 16. NumPy 2.5.4 is required in the existing runtime. The full canonical identity relies on the admitted immutable restore; the consumed prefix and each extracted row receive fresh hashes. No 2M ground-truth filtering or old 100-query membership report is used. Logical reads and duplicate-check/GT passes remain charged separately from physical I/O.

Calibration evaluates exactly two FP-centroid policies: per-level beam 32 or 36, both with tau 2.0, one-bit posting scoring, k = 100 and 400 exact candidates. There is no final leaf truncation. Each cell runs one declared warm-up pass then one retained pass. Eligibility requires mean recall at least 95% and actual internal pruning on at least 26 of 32 calibration queries. The lowest mean raw posting-row cost wins, with centroid evaluations and catalog order as tie breakers. The package writes and fsyncs a create-new selection artifact, pins its hash, and records a lock descriptor before it loads evaluation labels or starts any evaluation reader. It verifies that hash throughout evaluation. If any arm lacks an eligible policy, it preserves a scientific negative and never evaluates or lowers the target.

Evaluation uses each locked policy once on the 256 reserved queries, with a declared warm-up and retained pass. At least 205 queries per arm must actually prune internal nodes. Existing per-level validation checks completeness, kind partitions, expansion chains and cumulative counts. Retained traces show first pure-internal frontiers of 39, 49 and 49; beam 36 stays below them, but the new actual gate still decides. A missed gate is structural insufficiency with no automatic size increase or replacement policy. The corpus size is not assumed sufficient for 95% recall.

The new ground truth joins directly to complete pretrim, retained and returned candidate IDs. Dense identity maps are verified before joining. The first stage is reached-current-candidate coverage; it is not an independent selected-leaf membership census. Its complement is labeled unreached-current-candidate loss, followed by trim and exact-return losses. The immutable saved census supports the input assumptions, but no new query membership audit is hidden in timing. Returned IDs, FP32 distance bits, actual leaves, centroid evaluations, raw posting rows, distinct candidates, exact reranks, preload payload and raw traffic observations are retained. FP32 and FP64 tie behavior can differ.

Inference is frozen in INFERENCE-CONTRACT.json. It uses SplitMix64 with unsigned seed 2,026,101,701, rejection-sampled query indices and 10,000 shared paired resamples. Quantiles use sorted linear interpolation at (B - 1) times p. Five 99% two-sided intervals use p = 0.005 and 0.995: three absolute recalls and two dynamic-minus-reference differences. Bonferroni gives an approximate 95% conditional family under the resampling assumptions. A conditional comparison passes only when every absolute lower bound is at least 95%, both difference intervals fit within minus/plus one percentage point, and structural gates pass. Other outcomes remain target-not-met, quality-mismatch, structurally-insufficient or inconclusive. Deterministically spread and potentially correlated documents do not become a population sample because a lower bound clears a target. One tree per arm also leaves between-build uncertainty unmeasured. There is no retuning, sample extension or general equivalence claim.

The reused binary's per-ID observation map truncates at 256 entries when reranking 400 candidates. The package never calls that map complete. The frozen-source audit permits only a narrow aggregate classification: the block map must stay strictly below its own 256-entry cap, the point map must contain exactly 256 entries, the separate scalar batch map must be empty, all accesses must succeed, and complete block request totals must equal actual exact get attempts. Monotonic block-map insertion then proves no aggregate block was dropped. Otherwise aggregate traffic is explicitly unavailable. The accepted binary and observation caps remain unchanged. Encoded successful returns are not physical I/O or network traffic, and preload traffic is separate. A global saved reader does not measure actor fanout.

The proposed fresh external window is at most 900 seconds and $0.15, with 180 seconds reserved before shutdown. The package creates no resources or watchdog. Parent resource, sandbox, upload, protected-resource, shutdown and $1,000 cumulative budget restrictions remain.

Original manifests, maps and all saved-store paths are verified before and after queries. Each store inventory is bounded to 10,000 files and 512 MiB. Original manifest/map hashes are admitted evidence; the new object inventory is not a backdated independent hash receipt. Failures preserve prior cells and logs. No retry, seed search, corpus replacement, download to Mac or automatic larger run occurs.

The executable returns zero for a completed evaluated result, including an honest negative or inconclusive scientific outcome, two for calibration failure with no evaluation, and one for operational or integrity failure. Collection must preserve all three cases and must never retry a calibration failure to force a pass. The only normal runtime command uses --spec. The --prepare and --analyze modes are bounded internal child stages, not separate launch instructions.
