# One separately declared calibration amendment

This package adds one calibration candidate after the original two-policy protocol ends with a valid failure. It does not overwrite that result, reuse its expired window or repeat its passing controls. Only the one-owner tree receives a new FP-centroid beam-38, rerank-400 calibration cell on the same 32 calibration documents. The reference and four-owner beam-36 results are reused by exact byte descriptors. The amendment learns from calibration, never evaluation. It is not a new independent calibration cohort or an automatic retry.

The 95% recall target remains fixed. The one new candidate must reach mean recall at least 95% and prune internal nodes on at least 26 of 32 queries. No additional beam, target reduction, corpus size or seed search follows a miss. The original first internal frontiers are 39, 49 and 49; the new one-owner width remains below its frontier, but actual trace validation still decides. The prior one-owner result returns 3,029 true hits, reaches 3,039 and needs 3,040 to pass. Improved reach alone therefore does not guarantee a pass after candidate trimming.

All inputs are reused under verified bindings. The admitted original runtime spec, setup spec, preparation, failed result, selection, lock and passing calibration result files are hash-bound. The original result must contain no evaluation or inference, and its failed arm must be exactly the one-owner tree. Each reused control must be the original selected beam-36 point with the same 32 query IDs, at least 95% mean recall and actual pruning. Preparation must retain the exact 288 document IDs, split rule, unique byte hashes, prefix identity and original query/ground-truth descriptors. A different cohort, changed artifact or previously evaluated original rejects before the new reader.

The new full selection contains reference beam 36, one-owner beam 38 and four-owner beam 36 only if the new candidate passes. It is created once, fsynced and sealed by a descriptor before reading evaluation labels or starting any evaluation reader. The selection is checked throughout evaluation. On failure, the package preserves a new scientific negative and starts no evaluation. There is no beam-32 or beam-36 calibration rerun.

Evaluation reuses the same reserved 256 queries and new-cohort FP64 prefix ground truth from the original setup. It never filters 2M ground truth or joins old 100-query membership reports. All query, map, root, generation, stage and raw-work checks are unchanged. Complete pretrim IDs yield reached-current-candidate coverage, not an independently audited selected-leaf membership join. The inherited 205-of-256 internal-pruning gate remains fixed. The exact original Linux binary and three original 16K trees are reused. Those trees predate live-prefix and split-input filtering; this does not validate newest-construction quality.

Inference is byte-identical to the accepted implementation. It uses 10,000 paired SplitMix64 resamples with seed 2,026,101,701 and linear quantiles 0.005/0.995. Five 99% two-sided intervals cover three absolute means and two dynamic-minus-reference differences, with approximate simultaneous 95% conditional coverage. A conditional comparison passes only if all absolute lower bounds are at least 95%, both paired intervals fit inside minus/plus one percentage point and pruning gates pass. Negative or inconclusive outcomes remain negative or inconclusive. Deterministic document dependence, semantic duplication, natural-query relevance and between-build uncertainty prevent population or general algorithm equivalence claims.

The unchanged request-level observer keeps its bounded per-ID map incomplete. Lazy leaf-centroid reads can make warm-up vector requests exceed 400; the conservative aggregate classifier then reports unavailable rather than zero. Only independently complete aggregate block traffic is reported. Logical/provider/encoded-return work is separate from physical I/O or network traffic. Timing is traced warm elapsed, not a production latency study. A global saved reader does not measure actor fanout.

The proposal keeps one fresh window at most 900 seconds and $0.15, with 180 seconds reserved before shutdown. No build, corpus extraction, prefix copy or ground-truth computation is needed. Scientific work is capped at 150 seconds: admission inventories have 20 seconds, the single calibration cell 10, three evaluation cells 90 shared, inference 10, with the remaining time for orchestration and serialization. Final preservation has at most 30 seconds from the reserve. Every stage is also bounded by the external absolute deadline. There is no deadline extension or automatic retry. Parent sandbox, protected resources, upload approval, shutdown and cumulative $1,000 budget restrictions remain.

Original saved-store files and original failed artifacts are checked before and after. The free-disk floor is 20 GiB, stores are bounded at 10,000 files and 512 MiB each, observed cumulative child RSS at 8 GiB and metadata at 512 MiB. Final exact formatted output-size accounting reuses the accepted repair. These are observed stop conditions, not allocation bounds. New GT evidence copies contain IDs/distances only and are charged as metadata; no query vectors are copied for retrieval. All extracted document vectors and query/request payload files remain remote and are excluded from Mac collection.

The executable returns two for amended calibration failure with no evaluation, zero for a completed evaluation even if its conditional scientific outcome is negative or inconclusive, and one for operational/integrity failure. Every case is collected without retry. Only --spec is the normal entry point. The reused query-runtime analysis mode is an internal bounded child stage.

One local delta method passes five cases. Real fake-reader subprocesses prove exactly one new beam-38 calibration call, no old calibration reruns, full selection sealing before evaluation, and no evaluation on a candidate miss. It also rejects changed input bindings, an original result that already evaluated, and a changed selection before the next reader. All original inputs remain unchanged. The earlier scientific, ground-truth, inference, observation and cap tests are retained and are not repeated. No native source, build, corpus, network, cloud or real query payload is used locally.
