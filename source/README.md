# Measure grouped scrub validation with four local owners

This two-arm diagnostic asks whether owner-grouped validation removes the measured scrub message cost while preserving current ownership, migrations and saved membership. The baseline uses individual current-version messages. The second arm groups at most 64 scrub rows by actual authoritative owner. Both keep direct current reads and predicate batching disabled. This measures a grouped-owner operation through local actors; it does not establish physical network cost or cross-host performance.

Both arms consume the same retained first 8,192 vectors at 768 dimensions with inner-product distance, four construction threads and four owners. They use explicit full-precision navigation and neighbor predicates, branching four, split threshold 256, merge threshold 64, common balance cuts at 4,096/8,192 rows and joined-phase placement above 1,024 rows. Each arm independently requires multiple assigned scheduler regions, actual overlapping subtree contexts, completed balance, ownership movement and multiple populated owners. Full saved current-membership census, every saved vector bit and full-ID exact distance parity remain required. Exact scrub/code order remains covered by the accepted fixed local oracle and saved posting-code tests rather than a new native code oracle. These diagnostic thresholds do not represent ANN quality tuning.

The native boolean `batched_scrub_validation` defaults to false and requires the owner treatment when true. Both consumed spec and owner report echo it. The only other source change counts actual row identities in owner validation requests. `scrub_validation_rows` counts all physical rows considered; a row with no owner directory entry sends no request. `scrub_validation_request_rows` counts actual requested row identities, including repeated identities when physical rows repeat. Logical ID payload is four bytes per requested row. A one-byte-per-request version value estimate is an upper bound for the returned optional version values. Both exclude presence bits, slot indexes, message framing, actor allocations and protocol overhead, so neither is network traffic or total message bytes.

It partitions observed current callbacks into grouped validation requests and remaining individual current callbacks.
