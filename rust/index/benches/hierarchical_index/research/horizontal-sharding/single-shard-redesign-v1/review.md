## Recovery review limits

The inspected owner interface follows root replacement directly from the engine and rejects all four cross-machine operations explicitly. Resident records release map bucket guards before taking node locks; retirement empties old handles before unlinking and replacement cannot revive them. Structural preparation runs outside region reservations. Physical posting transfer claims the source and available destinations, compacts the source from its current rows and appends each accepted row to one destination. A mutation unwind poisons saving. These properties support the single-owner implementation scope; they do not establish cross-machine execution.

A shallow tree can reserve the global root for every short publication because changing a parent centroid refreshes the next ancestor’s packed row. Preparation remains parallel, but this publication serialization is a possible measured cost. The aggregate queue budget and eight outer rounds can leave residual size violations when membership transfers are complete. Record residuals, queue work, tree shape and wait/hold times; a successful save establishes exact membership rather than every configured balance threshold.
