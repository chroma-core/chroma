# Append from the current complete registration

A new write derives its fence from the current captured collection and the complete bundle registered in its vector segment. The namespace artifact describes saved identity mappings and construction history. Reusing that artifact does not reuse its construction parent's write authority.

The Rust current-view auditor takes the actual collection, record segment and vector segment from one captured context. It resolves the single registered bundle reference itself, checks its exact artifact and collection version/log/count relationship, obtains the namespace and construction receipt from that bundle, and matches the current record files, canonical vector artifact and owner maps. It checks stable collection configuration and identity separately from version, log position, count and publication timestamps. It then fully reopens the actual record maps and returns a private write-capable admission whose fence comes from the current enclosing deployment. No caller-supplied old/current pair or serialized audit receipt grants authority.

The next actual exporter opens the captured parent record store instead of constructing another record parent. Its input includes the exact captured bundle and collection binding; the runtime checks the current vector segment reference before creating an allocator. The materializer and record writer consume the admitted current view. The export pins that exact registered bundle, current collection version/log/count, vector deployment hash/fence and namespace artifact. The existing add-only and u32 exhaustion checks remain.

The bounded fixture first uses the accepted sixteen-to-eighteen-row path. A placement-only publication then creates another complete collection bundle with a higher collection version and deployment placement fence. It preserves the namespace artifact, canonical vectors, owner maps and every record file exactly. The fake authority uses that complete candidate as its current state; no local placement pointer advances. The next export captures this new bundle and appends two actual raw Add rows from its current log position, producing twenty saved records and vectors. The namespace table keeps every prior assignment, while its parent artifact points to the exact unchanged eighteen-row namespace.

A stale capture that carries the preceding bundle despite the same namespace artifact must reject against the delegate's current captured state before allocation or writes. A second check before registration submission rejects a moved or advanced authority and blocks the whole proposal. The fixture retains both append exports, placement proposal/bundle, actual full record audits, old mapping prefixes, saved selected-leaf memberships and the final complete registration. It does not claim real SysDb, service authentication, physical worker migration or production atomicity from the fake authority.
