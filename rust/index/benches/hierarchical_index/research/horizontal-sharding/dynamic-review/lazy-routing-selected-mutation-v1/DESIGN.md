# Route against immutable nodes, then open selected writers

The POC selects destinations without first loading a mutable writer for every owner. It assumes one fully audited immutable parent, one owner per global ID, an add-only batch and no balancing. A separate read-only router fetches exact persisted full-precision centroids and ordered children only for reached nodes. After all new rows route, it drops these readers and opens mutable writers only for selected owners. The global beam, boundary aliases, numeric distance arithmetic and total-order ties remain identical to the eager writer.

The paired baseline captures a routing bootstrap before any registration. It fully opens both actual parent writers and computes reachable per-level widths plus a hash over every node kind, ID, parent, ordered child list and exact centroid bits. Posting length is excluded because additive registration changes it. The bootstrap binds parent deployment hash, owner slot/order, exact consumed manifest hash, all five saved root IDs, dimension, metric, full effective write-policy numeric bits and committed boundary alias bits. The separate existing full semantic audit supplies parent ownership/vector/version/posting coverage; counts alone do not prove ownership. All baseline/bootstrap encoded returns, node counts and centroid/child payload are retained and charged separately. This is an internal fixed-input experiment certificate, not a production storage authority or mutable-file safety claim.

The lazy path validates root/dimension/config/owner bindings, opens typed read-only roots with a fresh provider per owner and point-reads reached node metadata and centroids. Its copied global frontier algorithm retains mixed-depth leaves, applies the same global widths and exact write policy, and orders by distance.total_cmp, owner slot and node ID. Root scoring uses committed aliases rather than replacing them with persisted lower centroids. A cache admits at most 256 owned routing nodes per owner and child arrays at most 256 elements; frontier/visited/retained-leaf sets have explicit limits. These are operation-state limits after provider decode, not predecode/provider/cache/RSS limits. Every new row routes before any mutation. New IDs come from the actual materialized export as a contiguous admitted append range, with no remapping.

Every selected mutable writer is opened from the same five roots with a new provider and recaptured bootstrap equality is checked before the first registration. The preselected registration primitive checks exact next global ID, owner range, next local ID availability and selected leaf kind, then uses the unchanged direct leaf insertion. It does not reroute. All selected writers are checked before any row is registered. No balancing, centroid updates, topology changes or ownership reassignment occur during this batch. Save uses the accepted generation-only shared-object store and complete existing saved-owner semantic oracle.

Three focused Rust tests cover actual persisted uneven-depth trees, crossing and equal-root-score rows, signed zero, routes computed upfront versus sequential eager registration, and exact centroid/edge/ID/width invariance after every registration. They also cover invalid bootstrap widths/policy/root, nonfinite vector rejection before node fetch and duplicate/new-ID or nonleaf registration rejection. The tests and bounded benchmark build run only after independent whole-source review. Use pinned Rust1.92 locked/offline, two build jobs, debug0,20GiB free floor and1200s per command. Preserve all failures and exact resulting binary/source/log hashes.

One paired native 96→98 experiment uses the retained representative multi-block fixture, actual materializer rows, canonical prefix/tail view and independent saved route/map reference. Each measured mode receives its own separately charged 89,807-byte owned-store bootstrap. Eager baseline opens two mutable writers; lazy routing must open only one. Both must match every route and final fifty-row saved audit, both selected leaf memberships, all old global/local mappings and complete exact rerank output. Generation-one reader results must remain exact. All old object/store keys and source/input hashes remain unchanged. There is no new collection publication, head replacement, corpus, service, failure campaign or query-quality experiment.

Report eager/bootstrap all-owner encoded returns separately from lazy read-only routing returns and selected mutable-open returns. LocalStorage observation counts successful encoded returned bytes, not physical disk/network I/O or all provider/cache/decode work. Node requests/cache hits/fetched nodes and cached centroid/child payload are separate. Routing state reports frontier capacity, visited/leaves capacity, cloned node payload and an owned payload/slot estimate; BTree allocator metadata, parser buffers, temporary parent-group/distance vectors, provider pins/cache/decode, input rows, full selected writer and process memory are excluded. The estimate is not a complete heap or hard memory bound. Flat boundary scoring and owner root/manifest metadata remain O(owners). Selected full topology/map/construction input and semantic audits remain explicit costs.
