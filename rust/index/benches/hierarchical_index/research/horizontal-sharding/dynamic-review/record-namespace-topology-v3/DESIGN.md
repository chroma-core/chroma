A topology change replaces selected vector trees and their routing boundaries while preserving every record offset, user identity and global vector ID. The complete collection registration contains the new saved vector roots and updated namespace together; no local deployment pointer publishes independently.

The preparation adapter captures the current complete collection bundle and session, validates its namespace, and writes a private intent journal before rebuilding. It calls the existing topology preparation function, which validates full canonical coverage, saves affected real lower trees, checks duplicate-current postings, and rebuilds ownership pages and trie roots where present. It never calls the local topology publication function. Existing remote and multi-worker rebuild rejection stays in place.

The namespace candidate reuses the exact prior mapping, shared identity and canonical vector artifacts, with every record file unchanged. It replaces owner-map descriptors, records the current parent deployment and namespace artifact, and captures the target collection version. The record count, logical size and log position remain unchanged. A fresh actual record reader audits the candidate through the current-view resolver before the proposal becomes eligible. Submission repeats this audit and checks the exact current collection and session before issuing one registration request.

The registration proposal preserves unrelated segment keys and replaces only the selected vector bundle reference. It advances the collection version and the vector deployment fence together. An ambiguous acknowledgement remains unknown; only an exact candidate observation establishes a committed outcome. There is no retry based on an old-parent observation and no second namespace authority.

The first fixture uses the retained tiny same-worker parent. It splits one logical owner, merges the resulting siblings, and reassigns a bounded ID between same-worker owners. It checks unchanged namespace identity artifacts and record files, complete global coverage and exact vector values, actual saved lower-tree audit, stale capture and stale submission rejection, and a failed audit after private preparation that produces no eligible proposal or registration call. All partial outputs remain private. Physical worker execution, production service wiring and the full-worker build remain separate gaps.
