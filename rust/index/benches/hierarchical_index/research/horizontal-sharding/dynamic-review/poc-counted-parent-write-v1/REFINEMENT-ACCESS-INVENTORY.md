# Exact refinement access: source-only inventory

Exact refinement retrieves the original vector for each selected local ID and computes its FP32 distance. The default path launches up to32 candidate futures. Each point lookup resolves its physical block through the root's sparse index. A reader first checks its own held-block map, then the provider cache, then storage and Arrow decode. The default reader keeps all loaded blocks until a later clear. The serial bounded path clears its vector-only held map after every owned scalar result; a retained provider cache can satisfy the next ID without another fetch or decode, so repeated reader-map insertion alone is not repeated storage I/O.

A cold parallel burst can overlap requests for the same block. The reader releases its map lock before fetching; the second map check prevents replacing an already-held block but occurs after a competing fetch/decode can finish. The provider checks its cache before fetching without a per-block in-flight guard at this layer. Local and plain S3 fetch dispatch each execute their callback; admission-controlled S3 has a separate coalescing path whose exact decode sharing must be inspected before making a production-network claim. Source structure establishes a possibility, not observed amplification.

The next meaningful baseline should identify candidate-to-block mapping and count reader requests, provider cache obtains/hits, storage fetch callbacks and successful decodes separately for the same fixed candidate IDs. Compare cold default32, warm default32 and serial release using identical selected candidates and FP32 outputs. The existing retained multiblock fixture can test the mechanism, while the pilot's real-data logical candidate reuse cannot establish physical blocks or bytes without those identities. Do not infer decode work from loaded-map highwater, and do not implement coalescing until measured amplification appears. Any grouping path must preserve exact candidates/output and bounded owned-block lifetime; no query recall policy change belongs in that measurement.

This is source analysis only. No new instrumentation, runtime, storage change or optimization is activated. The next coherent experiment requires a complete source/controller and budget review.
