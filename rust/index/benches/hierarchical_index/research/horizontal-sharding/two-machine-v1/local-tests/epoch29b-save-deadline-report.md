# Bounded durable save deadline correction

A full owner save needs more time than a construction RPC because each owner uploads and verifies its posting objects sequentially. The remote save request uses the ordinary 30-second transport cap in candidate29, even though the caller requests 60 seconds. The local save continues after that remote timeout, and the coordinator joins its local writer before reporting the failure. This explains why the observed failure surfaces after roughly 100 seconds of saving. The timeout does not establish that the remote writer stopped or that its uploads failed; partial immutable objects remain evidence.

Candidate29b gives saving one 600-second budget, shared across every owner batch and conditional publication. The benchmark clamps that budget to its existing absolute shutdown deadline. The remote client carries only the remaining budget. After authentication and decoding, the server recognizes the save request and permits its longer reply budget. Ordinary construction requests, expansion calls, and unauthenticated frame reads retain their existing timeout. There is no wire-format change or automatic retry.

The coordinator joins all started owner workers before checking expiry, then checks again before publishing the new latest generation. An expired save therefore leaves immutable partial objects but does not begin the combined metadata phase after joined-owner expiry. In-flight synchronous storage calls remain nonpreemptible; the external process supervisor is the hard shutdown bound. Publication already in flight also cannot be cancelled by this check. This change does not alter per-owner upload serialization or claim a save throughput improvement.

The native distributed suite passes 268 tests, with the real S3 smoke ignored locally and the same unrelated concurrent split test explicitly excluded. A transport regression proves that a save can outlast the ordinary cap while normal calls and shorter caller deadlines still expire. A save regression gates both owners beyond the shared shutdown deadline, proves the coordinator waits for its local writer, then verifies that the previous latest descriptor and independent reader remain valid. All three native benchmark binaries build and their help commands pass. The initial compile error and intermediate successful suite remain in separate logs.
