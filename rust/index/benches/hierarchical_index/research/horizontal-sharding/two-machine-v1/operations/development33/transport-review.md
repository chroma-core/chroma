# Transport correctness review

The independent source review finds no remaining blocking correctness issue in the connection reuse and bounded worker implementation. The review compares the working epoch 33 source against the immutable epoch 32 source and covers request dependencies, framing, deadlines, admission limits, shutdown, and the accompanying diagnostics. The parent task owns full-suite execution and the cloud smoke test; this note does not claim a measured speedup.

Each active client call exclusively owns its socket, and a socket returns to the cache only after its complete reply is decoded. A stale cached socket can be replaced before sending. The transport never automatically replays a request after a write, preserving uncertainty when a mutation may have executed but its reply is lost.

The server reserves three data execution lanes because construction can call publication or export, and export can call chunk installation. Control requests retain their own execution pool. The reciprocal callback test occupies both servers' primary workers while requests traverse export and chunk lanes. This covers the identified nested data dependency pattern. Arbitrary recursive control requests and total connection saturation retain explicit overload failure semantics; this implementation does not promise universal progress for every saturated call graph.

A bounded decoder stage preserves parallel JSON decoding outside the readiness reactor. Admission counts pending, decoding, decoded-but-not-dispatched, and executing connections. Decoder completion queues are bounded indirectly by that admission count, and the raw frame body is released before retaining the decoded request. The exported capacity helper accounts for the three data lanes, control lane, decoder workers, and connection limits. Decoded structures and allocator overhead remain additional to the wire-frame payload bound.

The review identified and the implementation resolves four edge cases: idle time no longer consumes a reused connection's next request budget; reads and accepts have per-pass work limits; a frame completed on the final read quantum dispatches immediately; and handler completions release their active counts before newly decoded requests are dispatched. Wake sockets use nonblocking writes so shutdown joins cannot wait for an undrained notification buffer. Admitted handlers still own their computation deadlines, and shutdown joins mutable operations rather than abandoning them.

The diagnostic additions retain the latest 32 completion estimates separately from the longest 32 jobs, with a default for older serialized snapshots and no additional per-job work when detailed diagnostics are disabled. Periodic peer transport snapshots are explicitly cumulative endpoint observations. Completion estimates across owners require clock alignment, and a bounded tail does not reconstruct an entire dependency graph.

The worker reports 18 focused transport tests passing, including reuse, stale-cache replacement, no mutation replay after a lost reply, partial-frame progress, overload separation, and reciprocal nested calls. The parent records final test logs and integrated validation separately.
