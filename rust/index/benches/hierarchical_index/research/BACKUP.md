# Hierarchical SPANN research backup

The feature branch contains a point-in-time copy of the current sharded-index implementation and written research. It includes in-progress work and does not imply that every change has completed benchmark validation. The original research workspace remains independent and unchanged.

## Current source and documentation

The current source is captured from the active epoch34 working directory. Source remains in its repository paths, including benchmark entry points and required crate configuration outside the hierarchical-index subdirectory. Research documents, helper scripts and patches are under this directory with their original project-relative paths. The design is [DESIGN.md](horizontal-sharding/DESIGN.md), the plan is [CURRENT-PLAN.md](horizontal-sharding/CURRENT-PLAN.md), and the handoff is [NEW-CHAT-HANDOFF.md](horizontal-sharding/NEW-CHAT-HANDOFF.md).

## Scope and limitations

This backup contains source code, configuration needed by that source, patches and written documentation, including narrative benchmark reports. Raw logs, structured benchmark/result records, datasets, saved indexes, compiled binaries, build caches and compressed source archives are excluded. Documentation links to those excluded objects remain provenance references and may not resolve in this repository. Local filesystem paths and old operational deadlines in historical reports describe their recorded context; check current environment state before running anything.

Each archival branch is an independent source-only snapshot. It preserves selected UTF-8 source/document files byte-for-byte under `source/`, retaining original relative paths and executable modes. It does not claim to preserve an entire original archive or to establish ancestry between experiments. Some snapshots contain only a source subset; their original archive identity is recorded. Structured package configuration is retained where recognized, while arbitrary JSON output is excluded. These branches are backups, not independently certified buildable releases. Identical content is deduplicated by Git.
