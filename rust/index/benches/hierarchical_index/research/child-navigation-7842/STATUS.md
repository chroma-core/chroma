# Shared child navigation during balancing

The implementation is committed on `codex/balance-child-navigation-payload` at `cc6a16140`, based on the corrected control `39626fb14`. The candidate retains eager destination posting-list loading and isolates publishing child navigation during balancing.

Each parent shares its child IDs and contiguous full-precision child centroids through its immutable navigation reference. A search clones that reference and releases its map guard before scoring. A child-list mutation first invalidates the centroid array, then publishes matching IDs and centroids while holding the existing tree-structure lock. A changed internal centroid also refreshes its parent's payload. New roots and internal nodes receive payloads before becoming reachable. Temporary invalidation falls back to live child lookups. The stable tree is still refreshed after workers join and before the first add on a reopened writer.
